## Deskripsi Proses Pengerjaan Projek UTS

Dalam pengerjaan projek UTS ini, saya memulai dengan mencari ide dan menentukan tema website yang akan dibuat, yaitu **Glow & Gather – Katalog Lilin Aromaterapi** setelah menentukan tema. saya membuat file projekuts.html setelah itu saya membuat halaman utama yang berisi header, logo, menu navigasi, dan tampilan awal website. Setelah itu, saya melanjutkan membuat bagian katalog produk dengan menambahkan foto, nama, dan informasi produk. Selanjutnya, saya membuat halaman artikel dan mengatur tampilannya agar sesuai dengan tema website.

Selama proses pengerjaan, saya beberapa kali mengalami kesulitan, terutama dalam mengatur ukuran gambar, posisi tulisan, dan tampilan halaman agar lebih rapi. Jika ada bagian yang tidak sesuai atau terjadi kesalahan, saya mencoba mencari tahu penyebabnya dan bertanya untuk mendapatkan bantuan dalam memperbaiki kode. Setelah website selesai, saya mencoba menjalankannya untuk memastikan semua bagian bisa tampil dengan baik. Kemudian, saya mempublikasikan website menggunakan Netlify agar bisa diakses melalui link dan melakukan pengecekan performa menggunakan GTmetrix. Dari proses ini, saya belajar membuat website secara bertahap, mulai dari menyusun kode, mengatur tampilan, memperbaiki kesalahan, sampai website berhasil dipublikasikan.
